# Java Calculator

A simple calculator application built with Java and Java Swing.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Decimal numbers
* Negative numbers
* Error message for division by zero
* Graphical user interface with buttons and a display

## Technologies Used

* Java
* Java Swing
* IntelliJ IDEA

## How to Run The Calculator

1. Download or clone this repository.
2. Open the project in IntelliJ IDEA.
3. Open the `Main.java` file.
4. Run the program.
